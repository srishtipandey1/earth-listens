# 90-second demo: Earth Listens

The demo begins in silence, then opens with the newly available Arctic September sea-ice scene. The NSIDC source data is real and unmodified; no sample values are used.

| Time | Action and narration |
|---|---|
| 0:00-0:06 | **Silence.** Show the page without touching Play. “Earth has a story in its data. We begin with no sound until you choose to listen.” |
| 0:06-0:17 | Choose **Arctic sea ice — September extent** and point to About the data. “This is the Northern Hemisphere September record from the NSIDC Sea Ice Index, with one observed value for every year from 1979 through 2026.” |
| 0:17-0:30 | Set the year to 1979, enable **Compare periods**, and set the comparison year to 2012. “The 1981-2010 average in this dataset is 6.413333 million square kilometers. 1979 is 7.05; 2012 falls to 3.57.” |
| 0:30-0:43 | Press **Play**. “The 1979 side is above the reference and stays calm. The much lower 2012 extent adds tension, brightness, and a more unsettled sound.” |
| 0:43-0:55 | Point to the data note while playback is paused. “The NSIDC Version 4 guide documents an input-source switch: NSIDC-0051 through 2024, then AMSR2/NSIDC-0803 from 2025. It attributes that change to expected loss of SSMIS access and observed data degradation.” |
| 0:55-1:07 | Use ArrowLeft/ArrowRight on the year slider, press Space to play/pause, and press M to mute/unmute. “The controls work by keyboard, and the live announcement describes the selected year and extent.” |
| 1:07-1:19 | Select **Global temperature anomaly**, move to 2024, then open **About the data**. “The same instrument can play NASA GISS temperature. Its zero-anomaly reference and mapping are unchanged.” |
| 1:19-1:30 | Open **How we used AI**. “Two real scenes are bundled. Amazon vegetation remains unavailable until its official data can be acquired and verified.” |

## Before presenting

- Start with a fresh page load and leave audio silent until the deliberate Play action.
- Confirm the raw September extent file remains the supplied 1979-2026 sequence and the source transition note matches the current NSIDC guide.
- Confirm NASA attribution and current dataset terms, and check event AI-use/submission requirements.
- If either dataset fails to load, stop the demo and explain the error; do not substitute a sample.
